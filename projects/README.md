# Projects

One folder per project: `projects/<project-name>/`. To start one, copy [_template](_template/README.md), rename it, and fill in `00-charter/startup-workflow.md` and `status.md`. The structure and the phase gates follow the [startup workflow](../operating-model/startup-workflow.md). Phase 0 starts with the CEO's idea brief.
